# Fuga das Galinhas

Feito em jul/2022, na faculdade. Está aqui como arquivo: o código ficou do jeito que era na época.

Jogo 2D no estilo Frogger: você controla uma galinha que precisa atravessar a pista sem ser atropelada. Os carros saem de um spawner (`SpawnCar.cs`) e a câmera fica presa nos limites do cenário (`CamBounds.cs`).

## Como abrir

Abra a pasta do repositório pelo Unity Hub (Add project from disk). Usei o Unity 2020.3.36f1. A pasta Library não está no repositório; o Unity gera de novo na primeira vez que abre.

Outros projetos da faculdade: [projetos-da-faculdade](https://github.com/gustadimas/projetos-da-faculdade)
